**Q1:** Multiply the second equation by 3: 3x + 12y = 66. Subtract the first: 10y = 50, so y = 5 and x = 2.

**Q2:** Multiply the first by 2 and the second by 3: 4x + 6y = 26 and 15x − 6y = 12. Add: 19x = 38, so x = 2 and y = 3.

**Q3:** Rewrite as 2x + y = 7 and 3x − 4y = 5. Multiply the first by 4 and add: 11x = 33, so x = 3 and y = 1.

**Q4:** c + g = 20 and 2c + 4g = 56. Double the first and subtract: 2g = 16, so 8 goats and 12 chickens.

**Q5:** m + c = 5 and 3m + c = 11. Subtract: 2m = 6, so m = 3 and c = 2. The line is y = 3x + 2.
