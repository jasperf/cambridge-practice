Exothermic & Endothermic

Memory trick: Exo = exit → heat leaves, surroundings get hotter. Endo = into → heat is absorbed, surroundings get colder.

Temperature Change Calculations

Temperature change = end temperature − start temperature. A positive answer = heated up (exothermic). A negative answer = cooled down (endothermic).
